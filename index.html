Volunteer a device

You need a spare Android phone or tablet, a Raspberry Pi, a USB cable and a Wi‑Fi or Ethernet connection. Setup takes about 30 minutes. You host the session on your own Pi, and you earn money every time someone uses your device.

  1. Use a spare device

    Pick a phone or tablet with nothing personal on it. Back it up, then do a factory reset so it has no accounts, photos or saved passwords.

  2. Turn on Developer options

    Open Settings → About phone and tap Build number seven times. You’ll see a message that you’re now a developer.

  3. Turn on USB debugging

    Open Settings → System → Developer options and switch on USB debugging. Some phones also have Disable adb authorization timeout; switch that on too, so the Pi stays trusted.

  4. Keep the screen awake

    In Developer options, switch on Stay awake (screen stays on while charging). Set the screen lock to None so users can reach the home screen.

  5. Plug the phone into the Pi

    Use a good data cable, not a charge-only one. When the phone asks Allow USB debugging?, tick Always allow from this computer and tap Allow.

  6. Install the apps you want to offer

    Install apps from a fresh Google account made only for this device, or sideload APKs. Don’t sign in to your own accounts.

Your Pi runs three things: ws-scrcpy (shows the screen), the Cyclic agent (hosts your API and the session, and enforces your time limit), and a Cloudflare Tunnel (gives it a public HTTPS link). Users connect to your Pi directly. A session only starts after Cyclic has taken the user’s credits.

  1. Install Raspberry Pi OS

    Use Raspberry Pi Imager to write Raspberry Pi OS Lite (64‑bit) to a microSD card. In the settings menu, set a hostname, a strong password and your Wi‑Fi, and turn on SSH. A Pi 4 or newer with 2 GB RAM or more works well.

  2. Install the tools

    SSH into the Pi and run:

    sudo apt update && sudo apt full-upgrade -y
sudo apt install -y android-tools-adb git build-essential python3 curl
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

  3. Check the phone is visible

    adb devices

    You should see your phone with the status device. If it says unauthorized, unlock the phone and accept the prompt.

  4. Install ws-scrcpy (the screen viewer)

    git clone https://github.com/NetrisTV/ws-scrcpy.git
cd ws-scrcpy
npm install
npm start

    It listens on port 8000. Leave it running for now, then make it start on boot:

    sudo tee /etc/systemd/system/wsscrcpy.service > /dev/null <<'UNIT'
[Unit]
Description=ws-scrcpy
After=network-online.target
[Service]
User=pi
WorkingDirectory=/home/pi/ws-scrcpy
ExecStart=/usr/bin/npm start
Restart=always
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now wsscrcpy
    ws-scrcpy hasn’t had frequent updates. If npm install fails, try Node 16 or check the project’s GitHub issues. Change pi to your Linux username if it’s different.

  5. Download the Cyclic agent

    The agent is one file with no extra packages to install.

    mkdir -p ~/cyclic && cd ~/cyclic
curl -O https://YOUR-SITE/pi-agent/server.js
curl -o config.json https://YOUR-SITE/pi-agent/config.example.json

  6. Set your price and time limit

    Edit config.json with nano config.json:

    {
  "cyclicSecret": "paste-it-in-step-9",
  "price": 2,
  "currency": "USD",
  "timeLimitMinutes": 30,
  "allowedOrigin": "https://YOUR-NAME.github.io"
}

    price is US dollars per session (0 is free). It’s charged in credits and rounds up to the next 10¢. timeLimitMinutes is how long each session lasts. Android version, RAM and phone/tablet type are read from the phone automatically. allowedOrigin is this site’s address, because the Cyclic host’s browser talks to your Pi directly. You’ll get cyclicSecret when you list the device in step 9, so leave it for now.

  7. Run the agent on boot

    sudo tee /etc/systemd/system/cyclic.service > /dev/null <<'UNIT'
[Unit]
Description=Cyclic agent
After=network-online.target
[Service]
User=pi
WorkingDirectory=/home/pi/cyclic
ExecStart=/usr/bin/node server.js
Restart=always
[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now cyclic
curl http://127.0.0.1:8080/api/info

    The last command should print your phone’s details.

  8. Get a public HTTPS link

    Point Cloudflare Tunnel at the agent (port 8080), not at ws-scrcpy. The agent only lets people through to ws-scrcpy during a paid session. For a quick test:

    curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64 -o cloudflared
chmod +x cloudflared
./cloudflared tunnel --url http://localhost:8080

    Copy the https://….trycloudflare.com link. It changes every run, so for a permanent address create a named tunnel in your Cloudflare dashboard.

  9. List your device and link the secret

    Open 3. List it and get paid, sign in, and paste your tunnel link. Cyclic gives you a cyclicSecret. Paste it into config.json, then run sudo systemctl restart cyclic. Until you do, your device can’t start sessions.

Keep it safe

  • Use a dedicated device with a factory reset. Never sign in to your own Google, banking or social accounts on it.
  • Factory reset the device between users if you can, or at least clear apps and data after each session.
  • The agent only lets people reach the screen during a session, and ends it when the time limit is up. Keep ws-scrcpy (port 8000) off the internet and expose only the agent through your tunnel.
  • Keep your cyclicSecret private. If it leaks, rotate it in your dashboard.
  • Check your local laws and your internet provider’s terms before sharing a connection.
  • Watch the first few sessions, and unplug the Pi if anyone misuses the device.

Users: what not to do

  • Don’t sign in to your own accounts or enter personal details or payment cards on a borrowed device.
  • Don’t use a device for anything illegal, abusive or that harms the volunteer.
  • Remember the volunteer can see what happens on their device.

Cyclic is a community project. Volunteers lend devices at their own risk, and you use them at yours.

Accounts and credits are kept on the device of VmThings, who hosts Cyclic from their browser. Your sign-in is saved in a cookie on this browser, and signing out deletes it.
